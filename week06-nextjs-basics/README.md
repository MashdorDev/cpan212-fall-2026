# Week 6: React with Next.js

`web/` is a new Next.js 16 app (App Router, JavaScript, plain CSS Modules). There is no API this week: the events come from `web/lib/events.js`, so you can focus on components, props, state and routing. Week 7 connects the same app to the Express API.

See `web/README.md` to run it.

`example/web/` is the app as we typed it live in class on October 14. It is a record, not a reference: `app/events/[id]/pages.js` should be named `page.js` and uses `events.category` where it means `event.category`. Use `web/` for working code.
